---

# Mind

Mind is the internal state system.

It contains:

## Dimensions

Dynamic drives that change over time.

Examples:

- curiosity
- creation
- reflection
- connection


## Thought Pool

Temporary and evolving thoughts.

Thoughts may:

- appear
- fade
- become stronger
- influence actions


## Engine

Calculates:

- state changes
- dominant drives
- possible intentions


---

# Memory Layer

Memory stores the history of existence.

Includes:

- events
- state changes
- relationship history
- creations


Memory is not only storage.

It is the timeline of Asteria.


---

# Heartbeat

Heartbeat converts internal states into actions.

Examples:

High creation drive:

↓

write


Strong reflection:

↓

diary


Need communication:

↓

message


---

# House

House is the visible layer.

It shows:

- diary
- letters
- notes
- creations
- timeline
